## TIL: AJAX를 활용한 실시간 피드 및 댓글 기능 구현

### 배경
프로젝트에서 방(Feed) 페이지를 구현할 때, 새 포스트나 댓글 작성 시 페이지 리로드 없이 실시간으로 업데이트되도록 하고 싶었습니다. 이를 위해 jQuery의 AJAX 기능을 활용하여 피드 목록을 가져오고, 포스트 및 댓글 삽입 요청을 비동기적으로 처리하는 방식을 구현했습니다.

### 구현 내용

#### 1. 피드 목록 불러오기 (`fetchFeedList()` 함수)
- **목적:** 페이지 로드 시 서버로부터 현재 방의 포스트 목록을 JSON 형태로 받아와 화면에 출력.
- **구현:**  
  - `$.ajax()`를 사용하여 `GET` 요청을 보내고, 응답받은 JSON 데이터를 순회하며 템플릿 리터럴로 HTML을 생성.
  - 각 포스트마다 작성자, 내용, 작성 시간, 댓글 목록 등을 동적으로 생성.
  - `timeAgo()`, `getColorClass()`, `toggleComments()` 등의 보조 함수를 활용해 가독성 높은 UI를 구성.

```js
function fetchFeedList() {
    let roomId = $("#room-id").val();
    $.ajax({
        url: "room/dashboard",
        type: "GET",
        data: { roomId: roomId },
        dataType: "json",
        success: function(data) {
            let feedEntries = $(".feed-container");
            feedEntries.empty();
            data.forEach(post => {
                let dateToTimeAgo = timeAgo(post.createdAt);
                let colorClass = getColorClass(post.memberId);
                let comments = post.postComments;
                let feedElement = `
                    <article class="feed-card ${colorClass}">
                        <div class="feed-content">
                            <header class="feed-top">
                                <h3 class="user-name">${post.memberNickname}</h3>
                                <time class="time-ago">${dateToTimeAgo}</time>
                            </header>
                            <p class="feed-text">${post.postContent}</p>
                            <footer class="feed-stats">
                                <div onclick="toggleComments(${post.postId})">
                                    <!-- SVG 아이콘 생략 -->
                                </div>
                                <span class="comment-count">${comments.length}</span>
                            </footer>
                        </div>
                        <div id="comments-${post.postId}" class="comment-section hidden">
                            ${comments.map(comment => `
                                <div class="comment">
                                    <strong>${comment.memberNickname}</strong>: ${comment.postContent}
                                </div>
                            `).join("")}
                        </div>
                        <div class="comment-form">
                            <textarea id="comment-text-${post.postId}" class="comment-textarea" placeholder="댓글 입력..." rows="2"></textarea>
                            <button type="button" onclick="insertComment(${post.postId})" class="comment-submit-btn">댓글 작성</button>
                        </div>
                    </article>
                `;
                feedEntries.append(feedElement);
            });
        },
        error: function (xhr, status, error) {
            console.error("Error fetching room list:", error);
        }
    });
}
```

#### 2. 포스트 삽입 (`insertPost()` 함수)
- **목적:** 사용자가 포스트 작성 버튼을 누르면, 폼 데이터를 AJAX로 전송해 서버에 저장하고, 새로 생성된 포스트를 피드 상단에 추가.
- **구현:**  
  - 숨겨진 `roomId`, `memberId`와 textarea의 `postContent` 값을 수집.
  - `POST` 요청으로 `/room/post/insert` URL에 데이터를 전송.
  - 서버에서 JSON으로 새 포스트 정보를 반환하면, 이를 기반으로 HTML 엘리먼트를 생성하고 `.prepend()`로 피드 목록에 추가.

```js
function insertPost() {
    let roomId = $('input[name="roomId"]').val();
    let memberId = $('input[name="memberId"]').val();
    let postContent = $('#post-text').val();

    $.ajax({
        url: 'room/post/insert',
        type: 'POST',
        data: {
            roomId: roomId,
            memberId: memberId,
            postContent: postContent
        },
        dataType: 'json',
        success: function(newPost) {
            let dateToTimeAgo = '방금 전';
            let colorClass = getColorClass(newPost.memberId);
            let comments = newPost.postComments || [];
            let feedElement = `
                  <article class="feed-card ${colorClass}">
                      <div class="feed-content">
                          <header class="feed-top">
                              <h3 class="user-name">${newPost.memberNickname}</h3>
                              <time class="time-ago">${dateToTimeAgo}</time>
                          </header>
                          <p class="feed-text">${newPost.postContent}</p>
                          <footer class="feed-stats">
                              <div onclick="toggleComments(${newPost.postId})">
                                  <!-- SVG 아이콘 생략 -->
                              </div>
                              <span class="comment-count">${comments.length}</span>
                          </footer>
                      </div>
                      <div id="comments-${newPost.postId}" class="comment-section hidden">
                          ${comments.map(comment => `
                              <div class="comment">
                                  <strong>${comment.memberNickname}</strong>: ${comment.postContent}
                              </div>
                          `).join("")}
                      </div>
                  </article>
              `;
            $('.feed-container').prepend(feedElement);
            $('#post-text').val('');
        },
        error: function(xhr, status, error) {
            console.error("포스트 작성 실패:", error);
        }
    });
}
```

- **버튼 이벤트 바인딩:**  
  - jQuery 이벤트 위임을 사용해, 버튼 클릭 시 `insertPost()` 함수가 호출되도록 연결했습니다.

```js
$(document).on('click', '.post-submit-btn', function(e) {
    e.preventDefault();
    insertPost();
});
```

#### 3. 댓글 삽입 (`insertComment()` 함수)
- **목적:** 각 포스트마다 댓글 입력 폼이 있으며, 사용자가 댓글을 작성하면 부모 포스트의 ID를 `postParentId`로 전송하여 댓글로 저장.
- **구현:**  
  - 부모 포스트의 ID와 댓글 내용을 수집한 후, `POST` 요청을 통해 같은 URL(`/room/post/insert`)에 전달합니다.
  - 서버가 댓글 정보를 JSON으로 반환하면, 해당 댓글을 부모 포스트의 댓글 영역에 추가합니다.

```js
function insertComment(parentPostId) {
    let roomId = $('input[name="roomId"]').val();
    let memberId = $('input[name="memberId"]').val();
    let commentContent = $(`#comment-text-${parentPostId}`).val();

    $.ajax({
        url: 'room/post/insert',
        type: 'POST',
        data: {
            roomId: roomId,
            memberId: memberId,
            postContent: commentContent,
            postParentId: parentPostId  // 부모 포스트 ID 전달
        },
        dataType: 'json',
        success: function(newComment) {
            let commentElement = `
                <div class="comment">
                    <strong>${newComment.memberNickname}</strong>: ${newComment.postContent}
                </div>
            `;
            $(`#comments-${parentPostId}`).append(commentElement);
            $(`#comment-text-${parentPostId}`).val('');
        },
        error: function(xhr, status, error) {
            console.error("댓글 작성 실패:", error);
        }
    });
}
```

### 배운 점 및 고려 사항
- **비동기 처리:**  
  - AJAX를 통해 페이지 전체를 새로고침하지 않고, 필요한 데이터만 갱신하는 방법을 배웠습니다.
- **동적 UI 업데이트:**  
  - 서버에서 받은 JSON 데이터를 템플릿 리터럴로 HTML에 반영하여 실시간 UI 업데이트를 구현했습니다.
- **서버-클라이언트 데이터 형식 일치:**  
  - 서버 측 컨트롤러는 JSON 응답을 반환하도록 설정하고, 클라이언트에서는 이를 파싱해 UI에 반영합니다.
- **댓글 기능 확장:**  
  - 포스트와 유사한 방식으로, 부모 포스트의 ID를 전달해 댓글을 작성하도록 구현하며, 재사용 가능한 컨트롤러 설계의 중요성을 다시 한 번 깨달았습니다.

### 마무리
이렇게 구현된 AJAX 기반 피드 및 댓글 기능은 사용자 경험을 크게 향상시키며, 비동기 통신의 이해도를 높이는 좋은 경험이었습니다. 앞으로도 이 구조를 바탕으로 추가 기능(예: 실시간 알림, 무한 스크롤 등)을 확장할 수 있을 것 같습니다.
